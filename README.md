# من Linux إلى الـ SOC — خريطة المسار الدراسي

موقع ثابت (Static Site) بخطة دراسية متسلسلة من **Linux Administration** إلى **SOC Analyst L1 ثم L2**، مع تتبع التقدم في المتصفح.

التصميم مبني على نمط موقع "من الشبكات إلى الـ SOC" (شريط تبويبات + حلقة تقدم + خط زمني بنقاط إنجاز)، والمحتوى الكامل منقول بالكامل من موقع Linux Roadmap: **127 درسًا في 16 مرحلة + 6 مصادر مراجعة إضافية** — بدون حذف أي عنصر.

## المحتوى

- **16 مرحلة**: من أساسيات Linux وتجهيز المعمل، مرورًا بالمستخدمين والصلاحيات، معالجة النصوص، العمليات والخدمات، الشبكات، السجلات، الحزم والتخزين، Bash، خدمات الويب، سجلات Windows وActive Directory، أساسيات SOC، SIEM (Wazuh/Splunk/Elastic)، MITRE ATT&CK، EDR، تحقيقات SOC L1، وصولًا إلى Threat Hunting وDFIR ومشروع SOC L2 النهائي.
- **كل درس يحمل**: العنوان بالعربية والإنجليزية، الوصف، ناتج التعلم، المحاضر ونبذته، الكورس ورقم الدرس، المدة أو وقت الدراسة المقترح، رابط المصدر، والنوع (فيديو/قراءة/لاب عملي).
- **اضغط على بطاقة أي درس** لتوسيع تفاصيله (الكورس، المحاضر، الوصف، ناتج الدرس).

## المزايا

- حلقة تقدم دائرية تحسب نسبة إنجاز الدروس المطلوبة (95 درسًا؛ الاختياري محسوب داخل المراحل).
- زر "اذهب للدرس التالي" ينقلك للدرس المطلوب التالي مع وميض تعريفي.
- تبويبات: المسار · مصادر المراجعة · خطة الأسابيع · المصادر الإضافية.
- بحث فوري + فلاتر (المطلوب/الاختياري، 25 محاضرًا/مصدرًا) + إخفاء المنتهي + تصفير التقدم.
- تقدمك محفوظ تلقائيًا في متصفحك (localStorage) ولا يُرسل لأي خادم.
- وضع داكن تلقائي حسب إعداد النظام، وتصميم متجاوب مع الموبايل.
- خط IBM Plex Sans Arabic، واتجاه RTL كامل.

## التشغيل محليًا

```bash
# أي خادم ملفات ثابت، مثلاً:
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

لا حاجة لأي بناء أو تثبيت — الموقع ملفات ثابتة فقط.

## النشر على Vercel

1. ارفع المجلد إلى مستودع GitHub.
2. في Vercel: **New Project → Import** المستودع.
3. Framework Preset: **Other** (Static). لا يحتاج Build Command ولا Output Directory (الجذر مباشرة).
4. Deploy.
